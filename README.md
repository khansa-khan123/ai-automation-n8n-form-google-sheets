 AI Automation Workflow — n8n + Webhook + Google Sheets

 Project Overview

This project demonstrates a simple automation workflow built with n8n.

The workflow receives data from a form through a webhook and automatically adds the submitted information to Google Sheets.

 Workflow

Form → Webhook → n8n → Google Sheets

 Tools Used

* n8n
* Webhooks
* Google Sheets

 How It Works

1. The user submits the form.
2. The form sends the data to the webhook.
3. n8n receives and processes the data.
4. The workflow sends the data to Google Sheets.
5. The submitted information is automatically stored in the Google Sheet.

 Project Result

The workflow successfully automates the transfer of form submissions to Google Sheets without manual data entry.

 Form

The form used to submit the data.

 n8n Workflow

The n8n workflow that handles the automation.

Google Sheets
